

Almanca ve İngilizce dil desteği, responsive menü, galeri ve demo sipariş akışı içeren React/Vite restoran sitesi.

## Yerel geliştirme

```bash
npm ci
npm run dev
```

## Üretim

```bash
npm run build
npm run preview
```

`main` dalına yapılan gönderimler GitHub Actions üzerinden GitHub Pages'a otomatik yayımlanır.
